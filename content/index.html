mita 服务端正在运行

这是 mieru【見える】代理体系的服务端。本应用没有管理界面——用 mieru / Clash 系客户端连接即可。

客户端连接参数

项目值
地址懒猫主机的内网 IP（局域网）或公网地址（需路由器端口转发）
端口部署时设置的「代理端口」
协议mieru（TCP；部署时启用 UDP 则也可用 UDP）
用户名 / 密码部署时设置的「代理用户名」「代理密码」
trafficPattern.seed部署时设置的「流量特征种子」——客户端 profile 里必须填写同一个数字，否则无法建立会话

推荐客户端

桌面：mieru 官方客户端、Clash Verge Rev、Mihomo Party
安卓：ClashMetaForAndroid、ClashMi、husi + mieru plugin
iOS：Karing、ClashMi

常用维护命令（应用终端）

mita status — 查看服务状态
mita get users — 查看用户用量
vi /lzcapp/var/mita/server.json — 编辑配置模板
mita apply config /lzcapp/var/mita/server.json && mita reload — 应用修改
